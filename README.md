# AVANE Employee Management Database

## Overview

This project is a relational employee management database designed and implemented using PostgreSQL.

The database was developed to organize and manage employee information including personal details, employment information, identification records, banking information, documents, and employment history.

## Objectives

- Organize employee information in a structured relational database
- Maintain relationships between employee records and supporting information
- Improve data integrity and consistency
- Enable efficient retrieval and reporting using SQL queries
- Demonstrate practical application of relational database design and PostgreSQL

## Database Structure

The database contains related tables for:

- Employees
- Departments
- Job Titles
- Employment Types
- Employment Status
- Marital Status
- Genders
- Identification
- Bank Details
- Documents
- Document Types
- Employment History

## Technologies

- PostgreSQL
- SQL
- Relational Database Design
- pgAdmin

## Key Features

- Relational table structure
- Primary and foreign keys
- Lookup/reference tables
- Data integrity constraints
- CSV data import
- SQL queries for data retrieval and analysis
- Employee identification system

## Data Privacy

This repository contains only fictional/sample data for demonstration purposes.

No real employee personal information, identification numbers, banking information, or confidential company data is included.
